# Meeting Notes

**Meeting Notes** — локальное настольное приложение для транскрибации записей встреч с возможностью генерации summary.  
Аудио и транскрипт обрабатываются **локально**. Во внешние сервисы отправляется **только текст**, и только если включено summary.

---

## Возможности

- Извлечение аудио из видео через встроенный **ffmpeg**.  
- Локальная транскрибация через **whisper.cpp** и выбранную модель Whisper.  
- Генерация `*_summary.md` через LLM по ключу пользователя.  
- Режимы:
  - **Только транскрипция**
  - **Только summary**
  - **Summary + транскрипт**
- Умный чанкинг для длинных текстов.
- Полностью автономная работа без интернета (если summary выключено).

---

## Зачем это нужно

Для рабочих созвонов, интервью, внутренних обсуждений, где критичны приватность, безопасность и соблюдение NDA.  
Все ключевые этапы обработки выполняются локально.

---

## Установка и запуск

1. Скачайте архив с последним релизом.
2. Распакуйте в удобную папку.
3. Запустите `MeetingNotes.exe`.

Приложение использует встроенные `ffmpeg` и `whisper-cli` из папки `bin/`.  
Модели Whisper нужно положить в папку `models/` рядом с приложением.

---

## Использование (GUI)

1. Запустите приложение.
2. Выберите медиа-файл (`mp4`, `mkv`, `avi`, `mov`, `webm`, `mp3`, `wav`, …).
3. Выберите режимы вывода:
   - **Generate summary (.md)**
   - **Save transcript (.txt)**
4. Если включено summary — введите API key.
5. Нажмите **Start**.

Итоговые файлы сохраняются рядом с оригинальным видео:

- `имя_файла_summary.md`
- `имя_файла_transcript.txt` (если включено)

---

## Обновление / добавление Whisper-моделей

1. Откройте релизы whisper.cpp:  
   https://github.com/ggerganov/whisper.cpp/releases
2. Скачайте файл модели `ggml-*.bin`.
3. Положите его в папку `models/` рядом с `.exe`.
4. Выберите модель в GUI → *Расширенные настройки*.

## Конфигурация

В корне приложения могут присутствовать два файла настроек:

### `settings.json` — общие настройки

```json
{
  "ffmpeg_path": "ffmpeg",
  "whisper_path": "bin/whisper-cli.exe",
  "whisper_model": "ggml-small.bin",

  "openrouter_model": "openai/gpt-4.1-nano",
  "summary_max_tokens": 1024,
  "summary_prompt": "prompts/summary_default.txt",

  "chunk_threshold_words": 4000,
  "chunk_max_words": 3500,
  "chunk_overlap_words": 200
}
```

### `settings_user.json` — персональные секреты

```json
{
  "openrouter_api_key": "sk-or-***"
}
```

> API-ключ нужен **только для summary**.  
> Можно использовать любой провайдер, совместимый с OpenAI-форматом запросов  
> (OpenRouter, Cloudflare Workers AI и др.).

## CLI (для продвинутых пользователей)

```bash
python -m src.cli "video.mp4" --lang ru
python -m src.cli "video.mp4" --summary
python -m src.cli "video.mp4" --summary --with-transcript
```

## Ограничения

- Скорость транскрипции зависит от CPU.
- Размер дистрибутива зависит от выбранной Whisper-модели.
- Для summary требуется API-ключ совместимого LLM-провайдера.
